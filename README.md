# Porti

Porti abre tu portón desde el teléfono.

## Descargar para Android

**[Descargar Porti](https://github.com/fibraraq/porti-descargas/releases/latest/download/porti.apk)**

El enlace baja siempre la versión más reciente.

## Cómo instalarla

1. Toca el enlace de arriba desde tu teléfono Android y espera a que termine la descarga.
2. Abre el archivo `porti.apk` desde la notificación o desde la carpeta Descargas.
3. Si el teléfono avisa que no permite instalar aplicaciones de esta fuente, toca
   **Configuración**, activa **Permitir desde esta fuente** y vuelve atrás.
4. Toca **Instalar** y luego **Abrir**.
5. Entra con tu correo y tu contraseña.

Después de instalarla, la mayoría de las mejoras llegan solas, sin volver a descargarla.
